# BF++

Язык `bf` является <<изотерическим>>, Тьюринг-полным языком программирования. Имея интерпретатор, он может описать любой алгоритм используя `+`, `-`, `[`, `]`, `>`, `<`, `.` и `,`.

## Команды BF

Классический `bf` работает с лентой ячеек и указателем на текущую ячейку. Программа состоит из восьми команд:

| Команда | Описание |
| --- | --- |
| `>` | Сдвинуть указатель на одну ячейку вправо. |
| `<` | Сдвинуть указатель на одну ячейку влево. |
| `+` | Увеличить значение текущей ячейки на 1. |
| `-` | Уменьшить значение текущей ячейки на 1. |
| `.` | Вывести значение текущей ячейки как символ. |
| `,` | Считать один символ ввода в текущую ячейку. |
| `[` | Если текущая ячейка равна 0, перейти за соответствующую `]`. |
| `]` | Если текущая ячейка не равна 0, перейти назад к соответствующей `[`. |

Вот так, например, выглядит классический "Привет мир" на этом языке:

```bf
подготовка ячеек с базовыми значениями
+++++++++[>+++++++>++++++++++>+++>+<<<<-]

печать Hello
>++.>+.+++++++..+++.

печать пробела
>++.

печать World
<<+++++++++++++++.>.+++.------.--------.

печать перевода строки
>+.>.
```

## BF++

Однако, есть код интерпретатора, который поддерживает расширение языка `bf` --- `bfpp`. Идея BF++ в том, чтобы сохранить минимализм Brainfuck, но добавить несколько возможностей для более удобной структуры программы: метки, переходы, функции, аргументы, возвращаемое значение и комментарии.

### Новые команды

| Команда | Описание |
| --- | --- |
| `^` | Перейти к метке. |
| `&` | Вызвать метку как функцию. |
| `$` | Загрузить возвращаемое значение последнего вызова функции в текущую ячейку. |
| `!` | Завершить выполнение функции и вернуться в место вызова. |
| `#` | Загрузить аргумент функции в текущую ячейку. |
| `*` | Сбросить текущую ячейку в 0. |
| `/` | Начать или закончить комментарий. |

### Метки

Метка задаётся любым незарегистрированным символом алфавита, например `a`, `f` или `z`. К такой метке можно перейти командой `^`, после которой указывается символ метки:

```bf
^z
```

Метка может находиться как до команды перехода, так и после неё. Например:

```bf
^z
+++.
z
+++++++.
```

### Функции

Любую метку можно вызвать как функцию с помощью команды `&`. Главное отличие функции от обычного перехода в том, что функция должна завершаться командой `!`, которая возвращает выполнение назад в место вызова.

```bf
^q
f
  +.
!
q

&f
```

Функции выполняются со своей лентой и своей позицией указателя. Передавать данные между вызывающим кодом и функцией можно через аргументы и возвращаемое значение.

### Аргументы и возвращаемое значение

Команда `#` загружает аргумент функции в текущую ячейку. После `#` указывается номер аргумента от `0` до `9`:

```bf
#0
```

Чтобы записать значение текущей ячейки в аргумент, используется цифра аргумента:

```bf
++++0
```

Команда `$` загружает возвращаемое значение последнего вызова функции в текущую ячейку. Возвращаемым значением считается значение текущей ячейки функции в момент выполнения `!`.

### Сброс ячейки

Команда `*` устанавливает значение текущей ячейки в 0:

```bf
++++*
```

### Комментарии

Текст между двумя символами `/` игнорируется интерпретатором:

```bf
/ это комментарий /
++++.
```

### Зачем нужен BF++

Допустим, нужно прочитать три байта и после каждого вывести перевод строки. В BF приходится трижды повторять подготовку ячейки со значением 10 и следить, чтобы временная ячейка снова была пустой:

```bf
,.>[-]++++++++++.<
,.>[-]++++++++++.<
,.>[-]++++++++++.<
```

В BF++ действие «прочитать и напечатать строку» можно описать один раз:

```bfpp
&l &l &l !

l
  ,. *++++++++++. !
```

Для ввода `ABC` обе программы выводят `A\nB\nC\n`. `&l` вызывает функцию, `*` очищает ячейку перед записью кода перевода строки, а `!` возвращает управление. Первый `!` завершает основную программу, поэтому тело функции ниже выполняется только по вызову. У каждого вызова своя лента: функции не требуется сохранять указатель и временные ячейки вызывающего кода. Для четвёртого символа достаточно добавить ещё один `&l`.
